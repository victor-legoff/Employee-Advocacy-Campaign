## Usage dans la stratégie de contenu

La chaîne YouTube sert de :
1. **Source de contenu** : les vidéos YouTube peuvent être résumées / transformées en posts LinkedIn
2. **Référence éditoriale** : ton, format, sujets traités
3. **Cross-promotion** : mentionner les vidéos dans les posts LinkedIn

## Workflow de Repurposing YouTube → LinkedIn

```
Vidéo YouTube publiée
  → Extraction transcript (via YouTube API ou outil tiers)
  → Claude résume en 3 points clés
  → Génération d'un post LinkedIn avec lien
  → Publication planifiée dans le Content Calendar
```
