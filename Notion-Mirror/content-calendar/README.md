# Notion Mirror — Table : Agenda de Contenu

## Propriétés Notion

| Propriété       | Type Notion   | Options / Format              |
|-----------------|---------------|-------------------------------|
| Date            | Date          | `YYYY-MM-DD`                  |
| Mois            | Texte         | Calculé                       |
| Jour_Semaine    | Select        | Lundi, Jeudi, Dimanche        |
| Theme_Principal | Select        | (liste ouverte)               |
| Type_Contenu    | Select        | Article, Question, Analyse, Étude de cas, Citation |
| Titre_Post      | Titre (Title) | Texte principal de la page    |
| Contenu_Post    | Texte riche   | Corps du post                 |
| Mots_Cles       | Multi-select  | Tags libres                   |
| Hashtags        | Texte         | `#tag1 #tag2`                 |
| URL_LinkedIn    | URL           | Lien post publié              |
| Statut          | Select        | Idée, Brouillon, Validé, Publié, Archivé |
| Note_Interne    | Texte         | Libre                         |

## Vue Notion recommandée

- **Vue Calendrier** : afficher par `Date`, filtrer sur `Statut != Archivé`
- **Vue Tableau** : grouper par `Statut`
- **Vue Timeline** : afficher sur 3 mois avec `Date`
