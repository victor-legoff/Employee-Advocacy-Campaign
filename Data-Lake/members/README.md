# Data Lake — Membres

Miroir de la table Notion **"Données des Membres"**.
Liste des collaborateurs participant à la campagne d'employee advocacy.

## Colonnes

| Colonne       | Type    | Description                          |
|---------------|---------|--------------------------------------|
| `Nom`         | Texte   | Nom de famille                       |
| `Prenom`      | Texte   | Prénom                               |
| `Email`       | Email   | Email professionnel                  |
| `URL_LinkedIn`| URL     | Profil LinkedIn                      |
| `Role`        | Texte   | Fonction dans l'entreprise           |
| `Actif`       | Bool    | Participe activement : `oui` / `non` |
| `Note`        | Texte   | Informations complémentaires         |
