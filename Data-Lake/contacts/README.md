# Data Lake — Contacts / Prospects

Miroir de la table Notion **"Liste des Contacts"**.

## Colonnes

| Colonne               | Type  | Description                                         | Valeurs possibles                            |
|-----------------------|-------|-----------------------------------------------------|----------------------------------------------|
| `Nom`                 | Texte | Nom de famille                                      | Libre                                        |
| `Prenom`              | Texte | Prénom                                              | Libre                                        |
| `Email`               | Email | Adresse email                                       | Libre                                        |
| `URL_LinkedIn`        | URL   | Profil LinkedIn                                     | `https://linkedin.com/in/...`                |
| `Entreprise`          | Texte | Entreprise du contact                               | Libre                                        |
| `Secteur`             | Texte | Secteur d'activité                                  | Hôtellerie, Immobilier, Retail, Tech…       |
| `Statut_Prospect`     | Texte | Stade du contact                                    | Froid / Tiède / Chaud / Client / Archivé    |
| `Dernier_Contact_Date`| Date  | Date de la dernière interaction                     | `YYYY-MM-DD`                                 |
| `Note`                | Texte | Contexte, besoins identifiés, suite à donner        | Libre                                        |
